备注 · 阅读前必看

看懂这些标记，后面的课程卡片就好读了。

难度
标记
  1. 纯水课会标注「水课」，不必给予什么关注
  2. 选修课程带「易高分」标记的表示比较容易拿高分
  3. 做项目一般指小组一起做，有些课程要求小组人数（但大部分不要）
  4. 期末考试形式的纸质考试若没有提及开卷则都是闭卷
  5. 未提及的选修课，可以上学院官网查询上一年是否安排过考试
  6. 没提到的资料可以去 BiliBili 或者 CSDN 搜（一定要善用！）
